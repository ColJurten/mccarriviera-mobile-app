## Story

As a staff member, I want to update a client's details, so that future contracts are correct while signed contracts keep what was signed.

## Acceptance criteria

- [ ] Every client field can be edited.
- [ ] Contracts already signed keep the client values printed at signature (snapshot).
- [ ] Edits are recorded in the audit trail, with values before and after.
