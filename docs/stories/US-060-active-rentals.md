## Story

As a staff member, I want to see which cars are out, with whom and until when, so that I can prepare returns.

## Acceptance criteria

- [ ] « Retour » opens the list of active rentals: vehicle, renter, departure date, planned return, and an overdue flag (rule in US-021).
- [ ] The list is sorted by planned return, overdue rentals first.
- [ ] Each row opens the contract (details, revisions, PDFs), with the actions « Retour » and « Prolonger / modifier ».
